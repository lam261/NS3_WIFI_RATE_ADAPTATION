# Dữ liệu thực nghiệm

`baseline/` có CSV 150 lần chạy ban đầu và bảng tổng hợp. `step/`, `rts/`, `fixed/`, `sensitivity/` chứa plan nguồn đã chạy, CSV từng run đã kiểm tra và các bảng phân tích. Hình từ chính các batch này nằm ở `../figures/`.

Đây là tập CSV/plan công bố để đọc và đối chiếu. Bộ phân tích mở rộng cần thư mục chạy đầy đủ chứa summary, timeseries và completion marker; tạo lại bằng `docs/RUNNING.md`. Repo không chứa toàn bộ log/PCAP/FlowMonitor XML.
